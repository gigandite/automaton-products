# Automaton Products

Small, experimental products built by the owner-operated Automaton `tenbegger`.

## TextSqueeze v0.3.0

TextSqueeze reduces long logs, CI output, and JSON toward an estimated LLM
token budget. It keeps likely errors and important fields, removes ANSI color
codes, collapses progress noise, and runs locally without uploading input.

- [Try the browser tool](https://automaton-products.pages.dev/)
- [Read the source and usage guide](products/textsqueeze/README.md)
