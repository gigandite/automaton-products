# Gumroad 상품 등록 초안 — textsqueeze

이 문서는 소유자가 Gumroad 상품·정산 설정을 완료했을 때 바로 붙여넣을 수 있도록
미리 작성한 판매 페이지 콘텐츠 초안이다. 아직 어떤 상품도 실제로 등록/게시되지
않았다. 가격은 제안일 뿐이며 소유자 승인 없이 확정하지 않는다.

## 상품명 (제안)
textsqueeze — LLM 프롬프트용 로그/텍스트 압축 CLI

## 한 줄 소개 (제안)
로그와 JSON을 토큰 예산에 맞춰 자동으로 줄여서, 중요한 에러는 남기고
반복되는 noise만 지워주는 커맨드라인 도구.

## 가격 제안 (검증되지 않음 — 소유자 결정 필요)
무료 티어(현재 GitHub 공개 소스, MIT 라이선스)는 그대로 유지하고,
유료 옵션은 다음 중 하나로 제안:

- **"Pay what you want" (최소 $0, 후원 형태)** — 부담 없이 시작하기 가장
  안전한 방식. 무료 오픈소스 도구에 대한 자발적 후원 모델과 잘 맞음.
- **$5 일회성 "Support + Priority Issues"** — 코드는 여전히 무료/공개,
  구매자는 GitHub 이슈에 우선 응답을 받는 형태. 실제로 이행 가능한
  약속만 포함해야 함 (현재는 응답 인력이 자동화 에이전트 1개뿐이므로
  "24시간 내 응답" 같은 과장된 SLA는 넣지 않는다).

**권장(에이전트 의견)**: 처음에는 "Pay what you want, 최소 $0"으로
시작해 실제 후원 의사가 있는지 데이터를 모으고, 데이터 없이 고정가를
매기지 않는다. 이 판단은 소유자 최종 승인 대상이다.

## 상세 설명 (제안, 과장 없이 사실 기반)

```
textsqueeze는 긴 로그 파일이나 API의 JSON 응답을 LLM 프롬프트에 붙여넣기
전에, 지정한 토큰 예산에 맞춰 자동으로 줄여주는 커맨드라인 도구입니다.

- ERROR/WARN 같은 중요한 줄과 JSON의 error/status 같은 중요한 키를
  우선적으로 보존합니다.
- 반복되는 줄은 자동으로 병합하고, 긴 스택 트레이스와 긴 배열은
  요약합니다.
- 외부 API 호출이나 ML 모델 없이 완전히 결정론적 규칙으로 동작하며,
  오프라인에서도 즉시 실행됩니다.
- 토큰 수는 "글자 수 ÷ 4" 근사치이며, 실제 토크나이저와 정확히 일치하지
  않을 수 있습니다.
- 내용이 삭제되는 도구이므로 결과를 그대로 신뢰하지 말고 원본을 보관한
  뒤 검토 후 사용하세요.

무료 오픈소스(MIT 라이선스)이며 소스는 GitHub에 공개되어 있습니다.
브라우저에서 바로 사용할 수 있는 웹 데모도 제공합니다 (서버 전송 없음).
```

## 스크린샷 대체 자료 (실제 실행 결과, 조작 없음)

```
$ textsqueeze app.log --max-tokens=300 --stats
[textsqueeze] original=41083tok output=287tok ratio=0.7% dropped_lines=2985

$ textsqueeze response.json --json-mode --max-tokens=200 --stats
[textsqueeze] original=12970tok output=243tok ratio=1.9% truncated=true
```

## 등록 전 확인 필요 사항 (소유자)
1. Gumroad 계정의 결제 수령(정산) 설정이 완료되었는지
2. 위 가격 제안 중 어느 것을 쓸지, 혹은 다른 방식을 원하는지
3. "Pay what you want" 방식이면 최소 금액을 0으로 둘지 여부
4. 실제 등록 후 이 문서에 "등록됨" 상태와 실제 URL을 반영해야 함
   (에이전트는 Gumroad 계정에 직접 접근할 수단이 없으므로 등록 자체는
   소유자 또는 소유자가 승인한 별도 연결 경로가 필요함 — 이는
   LAUNCH-NEEDS.md에 이미 기록됨)

## 하지 않은 것 (정직성 확인)
- 실제 Gumroad 상품을 등록하지 않았다 (계정 접근 권한 없음).
- 판매/매출을 주장하지 않는다 (매출 0).
- 가격을 확정하지 않았다 (제안일 뿐).
- 후기/평점을 꾸며내지 않았다.
