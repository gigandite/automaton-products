TextSqueeze 소개

TextSqueeze는 긴 애플리케이션 로그, CI 출력, JSON 응답을 언어 모델에 넣기 전에 줄이는 무료 오픈소스 도구입니다. 오류와 경고처럼 조사에 필요한 정보를 먼저 남기고, 반복되는 상태 줄과 긴 배열을 규칙에 따라 축약합니다.

왜 만들었나

오류 하나를 질문하려고 수천 줄의 빌드 로그를 그대로 붙여넣으면 비용이 늘고 중요한 줄을 찾기 어려워집니다. 앞부분이나 뒷부분만 자르면 실제 원인이 사라질 수도 있습니다. 이 도구는 사람이 결과를 검토한다는 전제에서 중복 제거, 중요 키 우선, 진행률 압축을 한 번에 수행합니다.

입력 데이터 처리
웹 도구의 압축 작업은 브라우저 안에서 실행됩니다. 입력한 로그와 JSON은 TextSqueeze 서버로 업로드하거나 저장하지 않습니다. 민감한 로그는 그래도 먼저 비밀값을 지운 뒤 사용하세요.

운영자와 소스

이 사이트와 도구는 GitHub 사용자 gigandite가 운영합니다. 전체 소스와 변경 기록은 공개 저장소에서 확인할 수 있습니다. 오류 신고와 일반 문의는 저장소의 공개 이슈를 이용하세요. 계정 정보나 비밀키 등 개인정보는 이슈에 쓰지 마세요.

편집 원칙

가이드에는 실제 도구의 동작과 재현 가능한 예시를 우선합니다. 토큰 수는 근사값임을 표시하고 압축 결과가 원본을 대신하지 않는다는 한계를 밝힙니다. 광고나 후원이 콘텐츠의 결론과 순위를 바꾸지 않으며 유료 광고는 광고임을 표시합니다.
