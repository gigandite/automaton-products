도구에 입력한 내용

TextSqueeze의 로그·텍스트·JSON 압축은 사용자의 브라우저에서 실행됩니다. 입력값과 압축 결과를 운영자 서버로 전송하거나 계정에 연결해 저장하지 않습니다. 별도 영구 저장 기능은 없지만 브라우저의 탭 복원이나 자동 완성 동작에 따라 입력이 남을 수 있으므로 공용 기기에서는 사용 후 입력을 지우세요.

호스팅 과정에서 처리될 수 있는 정보

사이트는 Cloudflare Pages에서 제공됩니다. 사이트 요청 과정에서 IP 주소, 브라우저 종류, 요청 시각과 같은 기술 정보가 보안·전송·장애 대응을 위해 호스팅 제공자에 의해 처리될 수 있습니다. 자세한 내용은 Cloudflare 개인정보처리방침에서 확인할 수 있습니다.

쿠키와 광고

현재 TextSqueeze 자체 기능은 사용자 계정이나 맞춤형 쿠키를 만들지 않습니다. 향후 Google AdSense 광고가 활성화되면 Google과 광고 파트너가 광고 제공, 빈도 제한, 측정 또는 맞춤설정을 위해 쿠키나 유사 기술을 사용할 수 있습니다. 광고가 활성화되는 경우 필요한 지역에는 동의 선택 기능을 제공하며 사용자는 Google 광고 설정에서 맞춤 광고를 관리할 수 있습니다.

외부 서비스

GitHub, Gumroad, 광고주 등 외부 링크를 열면 해당 서비스의 방침이 적용됩니다. TextSqueeze는 외부 사이트의 결제정보나 로그인 정보를 받지 않습니다.

보유·삭제와 문의

운영자는 도구 입력값을 수집하지 않으므로 해당 입력값에 대한 별도 보유 기간이 없습니다. 사이트 관련 문의는 GitHub 이슈에 개인정보를 제외하고 남길 수 있습니다. 민감한 정보는 이슈에 게시하지 말고, 필요한 경우 먼저 비공개 연락 방법을 문의하세요.
