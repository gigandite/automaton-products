처음 사용하는 방법

긴 빌드 로그나 API 응답을 AI에게 질문하기 전에 반복을 줄이는 도구입니다. 원본 기록은 따로 보관하고 결과에서 오류와 요청 ID가 남았는지 확인하세요.

  1. 일반 로그는 텍스트/로그, JSON 응답은 JSON 모드를 고릅니다. 먼저 예시 버튼으로 시험해도 됩니다.
  2. 입력창에 내용을 붙여넣고 목표 토큰 수를 정합니다. CI 로그에서는 ANSI 제거와 진행률 압축을 사용할 수 있습니다.
  3. 줄이기를 누른 뒤 원본과 결과를 비교합니다. 오류 원인이 빠졌다면 목표 값을 높이거나 필요한 줄을 직접 추가합니다.
  4. 복사하거나 파일로 다운로드합니다. 외부 AI에 전달하기 전 비밀키·개인정보는 직접 지워야 합니다.

자주 묻는 질문

ChatGPT·Claude의 정확한 토큰 수인가요?

아닙니다. 글자 수를 4로 나눈 근사치입니다. 한국어, 코드, 사용하는 모델에 따라 차이가 나며 API 비용 절감을 보장하지 않습니다.

목표 토큰 수를 넘을 수 있나요?

네. JSON 서식과 생략 표시 때문에 목표를 넘을 수 있습니다. 요청에 엄격한 제한이 있다면 해당 모델의 토크나이저로 확인하고 여유를 두세요.

중요한 오류는 모두 보존되나요?

ERROR/WARN과 주요 JSON 키를 우선하지만 완전한 보존을 보장하지 않습니다. 앞뒤 문맥과 배열 중간의 예외가 사라질 수 있으므로 원본과 대조하세요.

비밀키나 개인정보를 자동으로 지우나요?

아니요. 압축 도구이며 개인정보 마스킹 도구가 아닙니다. 외부에 공유하기 전에 비밀값을 직접 치환하세요.

로그를 업로드하거나 AI API를 호출하나요?

도구의 압축 처리는 브라우저 안에서 실행되며 입력을 업로드하거나 유료 AI API를 호출하지 않습니다. 사이트 접속 정보에 관한 내용은 개인정보처리방침을 확인하세요.

JSON 파싱 실패가 나오면 어떻게 하나요?

키와 문자열의 큰따옴표, 쉼표, 닫는 괄호를 확인하세요. 주석이나 여러 JSON 객체가 줄마다 이어진 JSONL은 일반 JSON과 다릅니다. 원문 로그로 줄이려면 텍스트/로그 모드를 선택하세요.

무료 버전과 지원판의 차이는 무엇인가요?

웹 도구와 MIT 라이선스 소스는 무료입니다. Gumroad 지원판은 소스 ZIP과 설명서를 내려받으며 프로젝트를 후원하는 선택 사항입니다.
