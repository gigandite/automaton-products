정적 랜딩 페이지 템플릿, 게시 가이드, 라이선스 문구 템플릿으로 구성된 3파일 패키지입니다.

패키지 구성

  • index.html — 구매자가 직접 수정하는 정적 랜딩 페이지 템플릿 (YOUR ... 자리만 채우면 됩니다)
  • GUIDE.md — 파일 구조, 수정 방법, 정적 호스팅 게시 절차
  • RIGHTS-TEMPLATE.md — 제품 라이선스/권리 표기 문구 템플릿

누구를 위한 것인가요

  • 디지털 제품(템플릿, 가이드, 소스 파일)을 정적 사이트로 처음 공개하려는 제작자
  • 프레임워크 없이 단일 HTML 파일로 랜딩 페이지를 빠르게 세우고 싶은 사람
  • 라이선스 문구를 어디서부터 써야 할지 모르는 초보 판매자

사용 방법

  • index.html의 YOUR ... 부분을 제품 이름, 설명, 가격, 판매 링크로 교체합니다.
  • GUIDE.md의 게시 절차를 따라 정적 호스팅에 올립니다.
  • RIGHTS-TEMPLATE.md의 문구를 제품 라이선스에 맞게调整后 사용합니다.
구매 전에는 각 템플릿의 내용을 확인하고, 자신의 제품과 사용 조건에 맞게 수정하세요.
